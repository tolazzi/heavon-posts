# heavon-posts

Imagens e registros dos posts diários do Instagram @agencia.heavon.

- `posts/AAAA-MM-DD/`: `reel/` (vídeo), `carrossel/` (slides) e `relatorio.md` de cada dia
- `historico.md`: lista dos posts publicados (usada para não repetir temas em 7 dias)
- `tools/render.js`: slides do carrossel; `tools/reel.py` + `tools/reel_render.js`: vídeo do Reels (rode `tools/setup_reel.sh` antes); `tools/publish.py`: publica pela Graph API
- `ROTINA.md`: instruções da rotina diária (Reels 09:00, carrossel 18:00)
