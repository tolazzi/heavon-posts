# heavon-posts

Imagens e registros dos posts diários do Instagram @agencia.heavon.

- `posts/AAAA-MM-DD/`: slides (1080x1350), `post.json`, `caption.txt` e `relatorio.md` de cada dia
- `historico.md`: lista dos posts publicados (usada para não repetir temas em 7 dias)
- `tools/render.js`: gera os slides; `tools/publish.py`: publica pela Graph API
